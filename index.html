知乎回答 · LLM 研究方向

无大算力时，作为学生，LLM 还有哪些值得做的研究？

BBugBuster喵·2026-04-04LLM

你如果觉得 RAG 和 Agent 没东西可研究，大概率是因为你看的还是两三年前那些非常基础的拼凑教程，比如调用一下 API 把文档切分、向量化存进去，然后再搜索出来丢给大模型生成答案。

今天的 AI 前沿研究，不仅不鄙视低算力方向，反而非常需要那些能在极低资源下解决复杂推理和数据治理问题的聪明大脑。

从相似度检索到检索轨迹

你以为的 RAG 是把文档切成文本块存到向量数据库里计算相似度，这是最原始的词汇或浅层语义检索。现在的真实痛点是，大模型的原生上下文窗口早就突破了一百万甚至两百万 token，单纯把文档全部塞进去模型虽然能跑，但是在海量上下文中精确定位特定信息的任务表现极差。

现在的 RAG 研究早就跨越了简单的向量检索，进入了复杂的检索轨迹规划和结构化知识融合阶段。 在真实的金融研报分析或者复杂的法律案件梳理中，一个复杂问题往往需要跨越多个文档节点才能得出结论。

这完全不需要训练大模型。你可以设计一种基于搜索树的探路算法，让小模型在检索库中学会按图索骥：模型先检索出第一份文档，阅读后发现信息不全，根据缺失的信息生成新的查询词，直到拼凑出完整的证据链。

知识图谱与 Agent

知识图谱结合检索的融合技术体系，是一个对 GPU 要求很低、但研究空间很大的方向。 如何把子图的拓扑结构转化为大模型能理解的线性输入，或研究图检索路由算法，都可以成为扎实的课题。

关于 Agent，核心研究点全在状态空间探索、多路树搜索算法和底层通信协议设计上。智能体每走一步，也就是提出一个诊断假设，我们就会调用一个经过特定准则微调的判别模型去给这个假设打分；如果某条推理路径得分太低，系统就会自动回溯到上一个合理节点。

动态评测：被低估的研究方向

目前行业内最缺的研究就是抗污染的动态评测机制和特定领域的深度评测基准构建。 传统静态选择题评测集可能已经被混进训练集，也无法反映模型在多轮交互、超长文本提取和复杂指令遵循上的真实能力。

作为独立研究者，你完全可以研究如何消除自动化打分的偏见：让裁判模型先提取文章的核心论点、逻辑推导链条和数据支撑，再针对每一个叶子节点进行规则化打分。
